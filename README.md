# UrbanStyle Data Cleaning with Pandas

This repository contains a Python project focused on cleaning and preparing customer data using Pandas. The project simulates how messy real-world business data can be transformed into a structured, analysis-ready dataset.

## Overview

The goal of this project is to clean and standardize a customer dataset for a retail company. It involves handling missing values, correcting data types, formatting text data, removing duplicates, and creating new features to support further analysis.

## Features

* Load and explore raw customer data
* Handle missing values using appropriate strategies
* Convert data types for dates and numeric fields
* Clean and standardize text data (names, categories, phone numbers)
* Identify and remove duplicate records
* Create derived features such as average purchase value and purchase frequency
* Sort and organize data for analysis
* Generate key business insights from the cleaned dataset
